# LetMeIn 🚪

Маленькая утилита для Windows, чтобы постучаться к соседу, когда он в наушниках и не слышит стук в дверь.

Клик по иконке в трее → пишешь сообщение → у соседа всплывает обычное уведомление Windows.

> **Проект полностью навайбкожен** — код написан ИИ, вручную толком не ревьюился и не проходил серьёзного тестирования.

## Возможности

- Работает **только в локальной сети** (один роутер), в интернет ничего не уходит
- Соседи находят друг друга автоматически — IP вводить не нужно
- Нативные уведомления Windows, висят ~25 секунд
- Кулдаун 1 минута между сообщениями — без спама
- Сообщения подписываются общим ключом, чужие устройства в сети ничего не отправят
- Трафик к соседу отправляется через домашнюю сеть в обход маршрутов VPN
- Один exe, сам устанавливается и добавляется в автозапуск
- Обновление в один клик прямо из программы, настройки сохраняются

## Установка

1. Скачай `LetMeIn.exe` из [Releases](../../releases).
2. Запусти его на **обоих** компьютерах. Программа сама установится, один раз попросит права администратора (для правил фаервола) и появится в трее.
3. Введи своё имя и **общий ключ** — любое слово, одинаковое на обоих компьютерах.

> Windows может предупредить, что файл неизвестный (exe не подписан): «Подробнее» → «Выполнить в любом случае».

## Использование

- **Левый клик** по иконке в трее — окно отправки: выбери соседа, напиши текст и нажми Enter.
- **Правый клик** — меню: настройки, автозапуск, проверка обновлений, перезапуск, удаление, выход.
- Наведи на иконку, чтобы увидеть, кто сейчас в сети.
- Если закрыл программу — найди **LetMeIn** в поиске Windows или набери `LetMeIn` в терминале.

## Если сосед не находится

- Сеть в Windows должна быть **«Частной»**: Параметры → Сеть и Интернет → Wi-Fi / Ethernet → Тип профиля сети.
- **Ключи** на обоих компьютерах должны совпадать.
- Гостевая Wi-Fi сеть или «изоляция клиентов» на роутере блокируют связь между устройствами.
- VPN с включённым kill switch может блокировать всю локальную сеть — разреши в нём доступ к LAN.
- В режиме «Не беспокоить» уведомления не всплывают, а сразу уходят в Центр уведомлений.

## Сборка из исходников

Нужен [.NET 9 SDK](https://dotnet.microsoft.com/download).

```powershell
dotnet publish LetMeIn -c Release -r win-x64 --self-contained `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:EnableCompressionInSingleFile=true -p:DebugType=none -o dist
```
